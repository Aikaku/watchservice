## 1단계. 탐지 엔진 다듬기 (03-06 ~ 03-11)

**핵심 목표: AI에 보내는 9개 피처를 정확하게 만들기**

### 피처 계산 개선
- 3초 윈도우로 이벤트를 모아 9개 피처를 계산한다.
- **rename 탐지**: DELETE와 CREATE 이벤트를 점수로 매칭한다.
- **암호화 의심 판정**: 엔트로피 증가 + 크기·확장자 변화가 함께 있거나, 엔트로피가 7.2 이상이면 의심으로 본다.
- **fileReadCount**: 5분 세션 단위로 센다.
- **엔트로피 샘플링**: 앞 40% / 중간 40% / 끝 20% 세 구간을 읽는다.
- 크로스 플랫폼 환경에서도 정확하게 동작하도록 보정했다.

### 시스템 기반 작업
- `CLAUDE.md`를 만들었다. 작업일지 작성, `ai_server/` 수정 금지 등 작업 규칙을 담았다.
- **동시 사용자 지원**: HTTP 세션마다 `ownerKey`를 발급해서 사용자별 데이터를 나눴다.
- **Gemini API 연결**: 탐지 시 AI 대응 가이드를 만든다. 토큰 수와 타임아웃을 조정했다.

### 보안 강화 (P0 ~ P3)
| 우선순위 | 내용 |
|----------|------|
| P0 | 관리자 비밀번호 BCrypt 해싱 |
| P1 | AI 서버 RestTemplate 타임아웃, CORS 환경변수화, HTTPS 설정 가이드 |
| P2 | 알림 통계 API, SQLite WAL 모드, logback 롤링 |
| P3 | Spring Security, 세션 타임아웃, Actuator |

### UX 개선

## 2단계. AI 서버 정비 + 문서화 (03-18 ~ 03-23)

### `api_server.py` 수정
`ai_server/` 폴더 중 이 파일만 편집할 수 있도록 규칙을 바꾼 뒤 진행했다.
- 위험도 점수를 benign이 아닌 모든 클래스 확률의 합으로 계산하게 했다 (다중 클래스 대응).
- 모델이 로드되지 않았으면 `/health`가 503을 반환한다.
- `fillna(-1)` 중복을 없애고, 누락된 피처의 기본값을 -1에서 0으로 바꿨다.
- CORS `allow_origins`를 환경변수로 제한했다.

## 7단계. 최종 버그 수정 마라톤 (05-18)

인수테스트를 실제로 돌리면서 나온 문제를 하루 동안 집중해서 고쳤다.

| 문제 | 원인 / 해결 |
|------|-------------|
| macOS "앱이 손상됨" 오류 | JRE 바이너리를 하나씩 서명한 뒤 앱 번들 서명. `afterAllArtifactBuild` 훅으로 DMG 안의 서명 유지. 첫 실행 안내에 `xattr` 명령어 추가 |
| 긴급 전체화면 경보가 뜨지 않음 | 폴링 요청에 세션 쿠키가 빠져 `ownerKey`가 맞지 않았음. 쿠키 포함하도록 수정 |
| DANGER 이메일 알림 미발송 | 서버를 재시작하면 `ownerKey`가 바뀜 → 고정값 `default`로 변경. `@Async`를 없애고 예외 처리 범위 확장. 최종적으로 잘 동작하던 "테스트 발송" 방식으로 발송 경로 교체 |
| Gemini 대응 가이드 응답 실패 | 타임아웃 2.5초 → 15초. 프롬프트 수정, 응답 토큰 수 로그 추가 |
| 팝업 알림 누락 / 소리 기본값 오류 | 구현 누락분 보완, 기본값 수정 |
| PDF 한글 깨짐 (S-10) | PDF에서 한글 문자 제거 |
| 로그 탭 전환 (S-11), 트레이 감시 상태 (S-13) | 탭 전환 수정, 트레이와 감시 상태 동기화 |
| `Object has been destroyed` 크래시 | `mainWindow.isDestroyed()` 체크 추가 |
| SMTP 등 환경변수 누락 | `.env`를 Electron 패키지 resources에 포함 |

- 파일 권한 감사 기능의 코드를 최종 제거했다.
- macOS와 Windows를 다시 빌드해 릴리스했고, 다운로드 사이트의 URL과 파일 크기를 갱신했다.
